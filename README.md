# Sky Command – GCS User Guide

**Basic Mission Creation and Corridor Task Execution**

This guide provides a basic overview of how to operate Sky Command, the Ground Control System (GCS) used by Tective for automated drone operations.

It is intended as a quick reference for new users and operators who need to perform a basic automated mission using the Sky Command interface.

**On a phone:** open [this page](https://tectivejk.github.io/Skycommand-Guide/) and add it to your home screen.

## 1. Starting Sky Command

1. On the GCS computer desktop, locate the Sky Command application icon.
2. Double-click the icon to launch the application.
3. Sky Command will open on the Mission Creation page.
4. Enter a name for the mission and click **Create Mission**.
5. The application will then automatically open the map view and display the current operating location in real time.

## 2. Checking the System Connection

Before starting any mission, verify that all required equipment is correctly connected and communicating with Sky Command.

Depending on the setup, you should see:

- The **Sky Hive**, if a Sky Hive is being used.
- The **drone**, if operating with a drone without a physical Sky Hive.

If the equipment is correctly connected, the relevant system components should be visible on the map.

Do not proceed with the mission if the expected equipment is not visible or the connection is not functioning correctly.

## 3. Editing the Holding Positions

Before creating a task, the Holding Positions around the Sky Hive must be checked and positioned correctly.

### To edit the Holding Positions

1. Press and hold the mouse button on the physical or virtual Sky Hive displayed on the map.
2. Select **Edit Holding Position** from the menu.
3. Sky Command will display five Holding Positions around the Sky Hive.
4. To move a Holding Position, click and hold the desired Holding Position with the mouse.
5. While holding the mouse button, move the Holding Position to the desired location on the map.
6. Position all Holding Positions on suitable, safe terrain.
7. Once all Holding Positions have been positioned correctly, click **Save** at the bottom of the screen.

### Holding Position Requirements

Holding Positions should be placed on:

- Clear ground
- Flat and stable surfaces
- Areas free of trees and other obstacles
- Locations suitable for a safe drone landing

Avoid placing Holding Positions on uneven terrain, vegetation, trees, buildings, or other areas that could create a landing hazard.

The purpose of correctly positioning the Holding Positions is to ensure that, if a drone is required to return to one of these positions, it can do so safely.

After clicking **Save**, the Holding Positions are updated and the system is ready for task creation.

## 4. Creating a Task

Once the Holding Positions have been checked and saved, you can create the mission task.

For this example, we will create a Corridor Task.

1. On the right-hand side of the Sky Command interface, locate and click **Add Task**.
2. Two task types will be displayed:
   - Corridor
   - Viewpoint
3. Select **Corridor**.

## 5. Creating the Corridor

The map will now allow you to create the corridor.

1. Click on the map to define the required waypoints and create the desired flight path.
2. Check the corridor carefully and make sure that the planned route is correct before continuing.
3. When the corridor has been completed, click **Editing Corridor**.

This will finish and lock the corridor task for the next stage of the mission setup.

## 6. Saving the Mission

After completing the corridor task, click **Save**.

The Save button is located in the bottom-right corner of the interface.

The mission will now be saved.

## 7. Starting the Mission

1. After saving the mission, click **Start**.
2. When the mission starts, the drone will appear in the Sky Command interface.
3. Allow a few seconds for the system and drone to initialize.
4. After the initialization process is complete, the **Arm** button will become available.

## 8. Arming the Drone

1. Once the **Arm** button becomes active, press **Arm**.
2. The drone will then arm and begin its automated take-off sequence.
3. After take-off, the drone will proceed to execute the configured Corridor Task according to the mission plan.
4. Monitor the drone and the Sky Command interface throughout the operation.

## 9. Completion of the Mission

After completing the Corridor Task, the drone will return according to the configured mission procedure.

Depending on the system configuration, the drone will return safely to its designated Holding Position or to the Sky Hive.

Monitor the drone and the Sky Command interface during the return and landing sequence.

## 10. Ending the Mission

Once the drone has safely completed the mission and the operation is finished, click **End Mission**.

The mission is now complete.

## Quick Reference – Basic Corridor Mission

1. Open Sky Command from the desktop.
2. Enter a mission name.
3. Click **Create Mission**.
4. Verify the Sky Hive or drone is visible and connected.
5. Press and hold on the physical or virtual Sky Hive.
6. Select **Edit Holding Position**.
7. Position the five Holding Positions on clear, flat and safe ground.
8. Click **Save** at the bottom of the screen.
9. Click **Add Task**.
10. Select **Corridor**.
11. Create the corridor using the required waypoints.
12. Click **Editing Corridor** to finish the corridor.
13. Click **Save**.
14. Click **Start**.
15. Wait for the drone to appear and initialize.
16. When available, click **Arm**.
17. Monitor the automated take-off and Corridor Task.
18. Monitor the drone’s return to the Holding Position or Sky Hive.
19. Once the mission is safely completed, click **End Mission**.

## Important

Always verify the equipment connection, Holding Positions, planned flight path, and surrounding area before starting an automated mission.

This guide describes the basic Sky Command workflow for a Corridor Task. Always follow the company’s operational procedures, safety requirements, and applicable flight regulations.
